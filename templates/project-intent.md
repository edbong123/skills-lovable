# Project Intent (template)

Ask these in plain language during /start. One question at a time. Keep it short — this is a lightweight PRD for no-coders.

1. In one sentence, what are you building?
2. Who is going to use it?
3. Is there anything the agent must NOT do, or must always do? (hard constraints)
4. Any tools/services already decided? (e.g. Supabase, Clerk, Stripe) — or say "detect it".

Write the answers into the **Project Intent** section of agents.md. This block is never overwritten by /update or logic updates.
